# Uncommon CCO Library

A curated library of Claude Code skills, templates, and playbooks for customer success leaders — built by the [Uncommon](https://uncommon.community) community. Fork this repo, customize what you need, and make it your own.

## What's a Claude Code skill?

Skills are markdown files that Claude Code can execute as slash commands. Once installed, you type `/skill-name` and Claude runs a structured, repeatable workflow — scoped to your codebase, your tools, your context.

## What's in here

| Folder | What it contains |
|---|---|
| `skills/` | Claude Code skills — install and run as slash commands |
| `artifacts/` | Templates, playbooks, and best practice guides |

### Skills

| Skill | What it does |
|---|---|
| `/cs-launch-enablement` | Turn raw product launch materials into a Notion-ready CS enablement guide |

## How to install a skill

1. Fork this repo
2. Copy any `.md` file from `skills/` into your project's `.claude/` directory (or `~/.claude/` for global use)
3. Open Claude Code and type the skill's slash command

## How to use an artifact

Artifacts in `artifacts/` are markdown templates and playbooks. Download, copy, and adapt them to your team's process.

## Contributing

All content in this library is curated by the [Uncommon](https://uncommon.community) community. Submit skills and artifacts through Uncommon for curator review — approved submissions get published here automatically.
